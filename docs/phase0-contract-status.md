# Phase 0 — contracts and toolchain decisions

**Historical record, September 17, 2026.** Phase 0 closed as documentation with qualifications, not technical acceptance. Statements below describe the decision and inspection at that time; see the [README](../README.md) for current implementation status.

The owner selected C++20 and Qt 6.11.1 from **vcpkg ports only**, dynamic `x64-windows`, MSVC 14.51.36231 from Visual Studio 2026, CMake 4.3.1-msvc1, and Ninja. The selected vcpkg baseline was `fa8cecf91d7f31a1715a7a6524f208897ffb33ce`. The local checkout at inspection differed and did not resolve the selected baseline object; no fetch, checkout, installation, configure, or build was run by the agent. The selection did not prove ABI, plugin, TLS, or clean-machine compatibility. Do not mix an external Qt SDK with the vcpkg build.

The owner-maintained reference client was the functional contract reference. The laboratory used email/password HTTP login at `http://127.0.0.1:8080/api/v1/webservice` and a 15.25 world endpoint at `localhost:7172`; TCP login port 7171 was distinct. The owner reported working client binaries and gameplay. The agent did not authenticate or connect in this historical phase. Two-factor challenges must block unsupported flows rather than be skipped.

The original QML resources were treated as immutable. Inspected imports included Qt Quick, Qt QML, Controls, Templates, GraphicalEffects, Effects, WebEngine, WebChannel, local `qmlcomponents`, and `QtQuick.LegacyControls`. Module descriptors and resource URLs require matching plugins, registered types, providers, and aliases; physical files alone do not prove runtime resolution. Private Qt APIs may vary with version. A future incompatibility must be addressed in permitted adapters or by revisiting the selected Qt version, never by patching protected QML.

The first asset inventory found all catalog references present but did not establish correspondence between local appearance IDs and server data. The historical inspection did not find translation catalogs in the original resource set; a catalog was extracted later. Verdana files were present locally without proof of visual metrics or redistribution. Exact protocol fields, Qt contracts, resources, and clean-machine build remained gates for their respective increments. This phase did not authorize build or execution by agents.
