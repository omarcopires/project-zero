# Phase 0 — authentication UI contracts

**Historical static QML inspection, September 17, 2026.** Paths in this document refer to `things/qt/qml/qmlcomponents/qml/`. The inspection did not prove component loading or implement authentication. Later integration is documented in [login and world entry](game-login-integration.md).

`TwoFactorEMailTextEnterDialog.qml` exists. Its controller uses `onOkClicked(text)`, `onCancelClicked()`, and an extra `onButtonClicked()` action associated visually with requesting a new email code. The item exposes `description`, `maxInputLength`, `enteredText`, `intOnly`, `buttonDescription`, `buttonVisible`, `additionalInfo`, and `additionalInfoTextVisible`. Its numeric regular expression limits characters but does not validate a code, expiration, or required length. Treat codes as strings to preserve leading zeroes. The QML alone does not prove TOTP, trusted-device, or recovery support.

`gamewindow.qml` calls `controller.loginPressed(email, password)` when the fields are nonempty and the screen is outside `INGAME`. This is a login intention, not proof of authentication. Enter triggers login; Escape clears the visual login mask but is not a network cancellation contract. The UI consumes `isAuthenticated`, `showCreateAccountOption`, `goToLogin()`, `goToCreateNewAccount()`, remember-email, password visibility, recovery, account creation, and Caps Lock state. A second login can be attempted before an earlier response arrives unless coordination prevents stale responses from authenticating the current attempt.

`CharacterSelection.qml` calls `onCharacterSelectionConfirmed(indices)` and `onCancelClicked()`. Selection and visual cancellation alone do not prove world connection lifecycle. Generic dialogs also have legacy spellings such as `confirmLable`; adapters must preserve names consumed by the original QML. Any future two-factor flow must correlate responses to the current attempt, prevent concurrent/replayed actions, avoid sensitive logs, and report unsupported challenges explicitly without simulating success.
