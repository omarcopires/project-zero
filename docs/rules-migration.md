# Origin and adaptation of AI rules

**Historical migration record, September 17, 2026; updated for the public repository in October 2026.** The owner's maintained reference client supplied examples of agent guidance, architecture, tests, formatting, and naming. Its paths are historical references, not a brand or engine to import. The current project rules live in [general instructions](../.github/copilot-instructions.md), [C++ instructions](../.github/instructions/cpp.instructions.md), [commit policy](../.github/instructions/commits.instructions.md), [coding standards](coding-standards.md), and [validation policy](validation-policy.md).

The original migration inspected the reference client's `.ai/agent.md`, architecture and sound-system documentation, formatting files, test/performance documents, sample C++ naming, and QML/OTUI import plans. It did not read logs, secrets, binaries, or dumps. Some source rules were adapted: Portuguese communication with the owner, English code/comments, documentation in `docs/`, Conventional Commits, no agent-run builds, clear ownership, isolated tests, and local `.clang-format` authority. Project documentation was changed to **English** when the repository became public; the historical Portuguese documents were rewritten in English.

Rules that would conflict with this project were not adopted: global source formatting, Lua/OTUI/ImGui tooling, OTClient globals (`g_ui`, `g_modules`, `g_logger`), QML-to-OTUI conversion, removal of legacy APIs consumed by the original QML, and treating reference-client test results as evidence for this engine. Where source rules disagreed about agent-run compiled tests, this project adopted the stricter prohibition. The owner later required Clean Architecture and Clean Code throughout new backend work, spdlog encapsulated in infrastructure, and one header per new enum class.

Protected original resources under `things/data/`, `things/images/`, `things/qt/`, `things/qt-project.org/`, `things/qtwebchannel/`, `things/spells/`, and `things/message.txt` remain byte-for-byte unchanged by agents. Modified copies, runtime replacements, and patches that alter frontend behavior are also forbidden. Resolve compatibility in new C++/Qt adapters, registrations, models, providers, and aliases, or document a blocker. These instructions are behavioral rules, not filesystem ACLs or a cryptographic guarantee.
