# Phase 0 — initial window and selection resource contracts

**Historical partial static inventory, September 17, 2026.** The initial scope was `clientwindow.qml`, `CharacterSelection.qml`, `OutfitAppearanceInstanceRenderer.qml`, and direct dependencies under `things/qt/qml/qmlcomponents/qml/`. Source line references from the original inspection were locators, not stable contracts. A literal URL, a physical file, and successful runtime URL resolution are separate evidence.

Seven literal `/images/...` paths were found in the three main consumers. Five mapped directly to original files (`title.jpg`, `icon-pin.png`, `maincharacter.png`, `icon-status-hidden.png`, `unknownoutfit.png`). Premium icon URLs required aliases from `/images/premium/icon-premium.png` and `/images/premium/icon-nopremium.png` to files at the original images root. Additional transitive controls use frames, scrollbar images, and `image://optimized1pixelborderimage/`; aliases alone do not implement image providers.

The original `clientwindow.qml` imports a `qrc:` module and uses a placeholder for composition. `CharacterSelection.qml` expects a controller and model with character name, level, vocation, world, outfit, daily reward, pin/main/hidden state, selection index, sorting/filtering, and premium data. Legacy table QML distinguishes `model[role]` from `modelData[role]`; exposing only `QAbstractItemModel` roles may not satisfy the full contract. Visible row indices must not be mistaken for stable character identity.

`OutfitAppearanceInstanceRenderer.qml` creates appearance instances as children of its renderer and replaces an instance list, but the old native setter's disposal semantics were unavailable. The new adapter must define ownership, avoid retained stale references or accumulation on updates, and synchronize rendering. An `unknownoutfit.png` fallback does not prove sprite availability. Font family, translations, sounds, dynamic premium URLs, Qt registration, and lifecycle services were other gates. Later work added assets, translations, providers, and Qt adapters; see [current rendering](world-map-rendering.md) and the [README](../README.md).

The original inspection only read QML/resources and matched filenames; it did not build, load QML, test graphics, connect to the server, or verify complete transitive coverage. Protected originals were not changed.
